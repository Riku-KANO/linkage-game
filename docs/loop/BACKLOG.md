## マイルストーン

1. **プロトタイプ** — 運動学ソルバーと 2D 設計ビュー。チェビシェフ・ヤンセンの脚先軌道が既知の形
2. **歩行** — 3D 試走ビューと動力学。ヤンセン型が平地を転ばずに歩く(ヤンセン型・チェビシェフ型・不格好な自作機構の 3 種で安定性を検証)
3. **ゲーム化** — 章 1・2、評価、保存、共有、ホーム画面と画面遷移。初見で 10 分以内に最初の歩行
4. **公開** — Cloudflare Pages
